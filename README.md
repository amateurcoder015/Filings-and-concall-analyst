# Filings & Concall Analyst

Ask questions about an Indian listed company's annual report, quarterly results and concall transcripts. Every claim in the answer is cited to a document, page and quote, and each quote is machine-verified against the page text.

**Status:** design phase. See [docs/superpowers/specs/2026-10-01-filings-analyst-design.md](docs/superpowers/specs/2026-10-01-filings-analyst-design.md).

## Planned v1
- One company (Infosys as placeholder), cited Q&A with a source viewer
- Agentic retrieval over a page index, with a deterministic quote verifier
- React frontend, FastAPI backend, SQLite index

For research and education only. Nothing here is investment advice.
